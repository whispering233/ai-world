# 时间探针 smoke（time-long / time-long-wait / time-long-inside）

- 2026-11-26
- 模型：`opencode-go/deepseek-v4.1-flash`（cognition/referee/narration/suggest）
- 目的：验证“时间钉死”是世界缺陷，还是默认 smoke 只喂短动作的测量假象。

## 1. 先看已有 20 拍

`data/starter-town/journal.jsonl`（`scripts/play.ts` 的 20 拍）：

| 拍 | 玩家输入 | duration | 效果 |
| :--- | :--- | ---: | :--- |
| 2 | 在靠墙的桌边坐了一会儿，等雨小一点 | 10 | clock 10 |
| 5 | 趴在靠墙的桌上睡了一整夜，天亮才醒 | **480** | clock 约 490 |
| 12 | 坐了一会儿，等雨小一点 | 10 | clock 约 500 |

20 拍结束 `clock=535`，即第 1 天早上 8:55。**裁判本来就能给 480 分钟**，短对话 12 拍走 17 分钟不是“钉死”。

## 2. 三次 `--long` 探针

`scripts/experiment-multi-round.ts --long` 在第 5 拍插入一个长动作：

| tag | 第 5 拍输入 | 结果 | 判断 |
| :--- | :--- | :--- | :--- |
| `time-long` | 趴在桌上睡一整夜，天亮才醒 | **拒绝**，duration 1；“外头仍是雨夜，天没亮过” | 正确：当时 clock 只有 9 分钟，不能跳到天亮 |
| `time-long-wait` | 坐在桌边等雨停，等四个钟头 | **拒绝**，duration 1；“你还隔在门板外头，桌边没有你的位子” | 正确：第一拍“推门进去”被拒后，玩家一直在门外 |
| `time-long-inside` | 先把第一拍改成“我在靠门的位子坐下”；第 5 拍等雨四个钟头 | **接受，duration 240**；clock 9→249，结束 256（**拂晓**） | 长动作本身成立 |

`time-long-inside` 汇总：

| 指标 | 值 |
| :--- | ---: |
| 拍均耗时 | 67.6s |
| 结束 clock | **256 分钟（拂晓）** |
| 长动作占比（`ok`+≥240） | **1.7%**（1/59） |
| no_rate | 6.8% |
| 空结果 | 67.8% |
| 动作提示 | 12/12 |
| 硬冲突 / 双花 / 失败 op | 1 / 1 / 0 |

硬冲突/双花来自实验脚本的 `detectConflicts`（用拍前持有核对整拍 transfer，未算同一裁决转入），不是这次长动作造成的；物质 op 是 transfer 11、phys 3、fact 8。

## 3. 结论

- **“时间钉死”是否证**：默认 smoke 的 12 拍全是短对话，17 分钟正确；长动作探针能落 240 分钟，`play` 的睡整夜能落 480 分钟。
- **不要给 `duration` 加强制下限**：两次长探针被拒都有账本/场景依据（天没亮、人在门外），不是裁判偷懒。
- **实验脚本的固定第一拍会污染后续探针**：`我推门进去` 可能被拒，之后“坐在桌边等”就变成门外等待。改成“我在靠门的位子坐下”后，长动作才成立。
- `--long` 保留为回归探针；默认不加，避免把短对话基线的 clock 改写。

## 4. 风险

- 只有一次“接受 240”的样本；长动作仍可能因场景不一致被拒，这是正确行为。
- `--long` 会改变 clock、空结果与 transfer 分布，不能和旧 tag 直接对比。
- 实验脚本的 `detectConflicts` 误报仍在；这次 hard/double 1 不应读成世界冲突。
