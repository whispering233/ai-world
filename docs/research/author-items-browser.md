# 作者表单 `items` 浏览器验证

- 2026-11-26
- 目的：确认作者壳能改物品显示名，保存写盘，不碰其他字段。

## 1. 保存

- 作者壳 →「内容」→ `items` 区块，把 `whiskey` 的显示名改成“威士忌酒”。
- 点“保存”，弹窗显示“内容已保存”，顶栏变“内容已变更，未生效”。
- 直接读 `content/starter-town.json`：`items.whiskey === "威士忌酒"`；`cup` 仍是“杯子”，`names.ann` 仍是“安”，`places.saloon` 仍是“酒馆”。
- 测试只保存、不重置；验证后已把 `content/starter-town.json` 恢复为原始内容，`data/starter-town` 也恢复，服务已停。

## 2. 校验

- 单测覆盖：空 item 名（被 holds 引用、未被引用、整键缺失）都会报 `物品 X 缺少显示名`；被多个持有者引用的缺键物品只报一次。
- `items` 不是对象时报 `items 必须是对象`，不会遍历字符串/原始值。
- 作者表单空 item 名保存时由 `validatePack` 拒绝；UI 不静默。

## 3. 结果

- `items` 与 `places`/`names` 已在同一面板；玩家可见的三类显示名都能在作者壳里改，不必手改 JSON。
- 改名只影响投影/上下文标签；`core`/`canon`/`opening` 里的旧称呼仍需作者同步（C1 的提示仍适用）。
- 357 测试、typecheck、build 绿。

## 4. 风险

- 浏览器只验证了保存写盘，没有在新局里买一杯看 `威士忌酒` 出现在持有列表；该路径由 `view` 的 items 映射单测覆盖。
- 作者改 item 名后，正文/旧事实里的旧物品名不会自动改；与人物显示名相同的 caveat。
