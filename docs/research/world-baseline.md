# 20 拍世界基线（2026-11-21）

- 模型：`opencode-go/deepseek-v4.1-flash`（cognition / referee / narration 同模型）
- 世界：`starter-town`，`rm -rf data` 后从零开始
- 命令：`npm run play -- --beats 20 --auto`
- op 名：`transfer`（任何持有变化）/ `consume`（物品离开世界）；旧 journal 的 `give`/`take` 仅作 replay 别名
- 探针：9 条室内循环（短对话 / 等待 10–30 分钟 / 物理 / 知识交换 / 喝掉），长动作只跑一次（第 5 拍），最后一拍单独测移动

## 时间：从两端变成“有中间值，但偏短”

本次长动作只跑一次，裁判接受了：

> 我趴在靠墙的桌上睡了一整夜，天亮才醒。 → `duration: 430`

中间探针也出现了两次：

> 我在靠墙的桌边坐了一会儿，等雨小一点。 → `duration: 20` / `8`

这是 W2 的关键变化：裁判不再用“从进门到现在才过了几分钟”拒绝长动作；`duration` 真正推动了 `clock`。但 4–30 分钟只有 2 次，31–239 分钟仍为 0，时间尺度还是偏“短动作 + 一次长睡”。

## 物质流：有真实过手，但量小

本次已提交 `transfer` 2、`consume` 1：

- 玩家把两枚银元 transfer 给安；
- 安把一杯威士忌 transfer 给玩家；
- 玩家 consume 那杯威士忌。

净持有变化：安 威士忌 -1；安 银元 +2；你 银元 -2。和 W1 的“来回抵消”不同，这次银元真正留在安手里，物质流是实的，但总量仍小。

一条 `transfer` 被回滚：`granny474` 想把没有的 silver-dollar transfer 出去，整条 claim 回滚。这不是显示名问题，是持有量校验生效。

## 知识通胀：80.2%

`know` 162 / 202。比 W1 的 67.2% 更高；`REFEREE_SYSTEM` rule 10 的“说话留痕”仍未动。W2 已把时间语义拆开，下一张应做 W3，否则每轮对话都在给全场发 `know`。

## 结论

- W2 目标达成：clock 只按已提交 claim 推进；长动作不再因“当前 clock 尚早”被拒；duration 分桶出现 4–30 的中间值。
- 时间仍偏两端：31–239 分钟没有样本；下一步可以在 W2 后续或 W3 前补一条“出远门/帮工半天”的探针，但不要加强制时长表。
- 物质流是实的，但小；W1 的 `transfer/consume` 已够用，不需要容器。
- 下一张优先 **W3 知识通胀**：`know_rate` 80.2%，比 W1 更严重。

## 限制

- 单次运行、单模型、自动探针；没有人工评分。
- 最后一拍 move 探针被格蕾妮挡门拒绝，`move 0` 不能说明移动能力消失；W1 已有一次成功 move。
- 430 分钟是模型给的值，不是固定 480；规则只要求长动作给大值，不规定具体数。
