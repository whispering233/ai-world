# 20 拍世界基线（2026-11-21）

- 模型：`opencode-go/deepseek-v4.1-flash`（cognition / referee / narration 同模型）
- 世界：`starter-town`，`rm -rf data` 后从零开始
- 命令：`npm run play -- --beats 20 --auto`
- op 名：`transfer`（任何持有变化）/ `consume`（物品离开世界）；旧 journal 的 `give`/`take` 仅作 replay 别名
- 探针：11 条循环（短对话 / 等待 10–30 分钟 / 物理 / 耳语谎言 / 喝掉），长动作只跑一次（第 5 拍），守卫探针在第 3、16、18 拍插入承诺 / 威胁 / 公开宣告，最后一拍单独测移动

## 事实密度：从 4.45 降到 1.10–1.20，未达 ≤1.0

三个可比样本：

| 版本 | 事实数 / 20 拍 | `facts/beat` |
| :--- | :--- | :--- |
| W3（未收窄） | 89 | 4.45 |
| W3b-B 迭代版 | 22 | 1.10 |
| W3b-B 最终版 | 24 | 1.20 |

`fact/claim` 从 0.99 降到 0.27，`know+fact` 占写操作的比例从 91.8% 降到 74%（26/35），世界的“记录”不再是唯一动作。

**判据未达标**：两次实测 1.10 / 1.20，均高于 1.0。差的这一点不是噪声，而是三类可命名的残留：

| 残留 | 样本 | 本应是什么 |
| :--- | :--- | :--- |
| 动作细节 | “格蕾妮横身半步挡住柜台后沿…”“格蕾妮松开一直压着的门闩…” | rule 8 说纯动作细节不记，但裁判仍把“当众做的动作”当事件 |
| 重复寒暄 | “玩家走到柜台前，问还有没有酒” | 与上一拍重复，属于已知信息 |
| 误归属 | 玩家 claim 的 fact 写成“安从玩家手里接过盛空杯的木盆…” | 裁判把动作的承受者当成主语，事实的主语错了 |

把这三类去掉，24 条剩 20 条 = 1.00。也就是说：**规则文本已经能把“语句级事件”挡住，但挡不住“动作级事件”和归属错误**。

## 守卫：5 类关键事件

| 守卫 | 探针 | 结果 |
| :--- | :--- | :--- |
| 交易 | 把两枚银元塞进安手里 | `transfer` + 安“账清了”的 fact |
| 承诺 | “明天中午之前把那两枚银元还上。” | fact + 安定下期限的 fact |
| 威胁 | “再听见有人提这笔账，今晚就走。” | fact + `rel` |
| 谎言 | 耳语“账本藏在柜台下面” | fact + `know`（只给医生） |
| 公开宣告 | “今晚这店我包了。” | 玩家侧无 op；安的“回绝包店”落了 fact |

前四类干净，第五类只记了对方的回应，没记宣告本身。

## 知识：`know` 回到 2 条，听众正确

W3 收窄后 `know` 1 条；W3b-B 实测 2 条：

- 耳语 → `doc`；
- 科迪“我私下告诉过医生柜台底下有铁盒” → `ann / granny / player`。

没有回到逐句广播。转述那句是公开说的，把三个听众都标上是对的。

## 结论

- rule 8 收窄有效：`facts/beat` 4.45 → 1.10–1.20，`fact` 不再是台词账本。
- **未达 ≤1.0**。差的 20% 是“动作细节”与“主语归属”，不是随机波动；继续压需要改“什么算事件”的措辞或加解析层校验，属于下一张卡的决策。
- 5 类守卫里 4 类干净，公开宣告只记了回应。
- `no_rate` 11.0%，仍低于 15% 下限；这是从 W2 起就有的偏差，不属于本卡。
- 空结果占比的语义变了：纯对话没有 delta 是正常的，指标已改成同时看“无变化拍”（5/20）。

## 限制

- 单次运行、单模型、自动探针；两版 prompt 各跑一次，方差未测。
- `transfer` 3 条但净持有只变了银元，本轮没有酒的实际转移，物质流样本不足。
- `move` 0：最后一拍出门未落 op（被拒或裁判没写），不能据此判断移动能力。
