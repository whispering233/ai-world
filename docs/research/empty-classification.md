# 空结果分类（baseline-20）

- 2026-11-26
- 样本：`baseline-20` 的 100 条裁决，其中 **77 条 `ok` + 空 deltas**
- 目的：判断“77% 空结果”是裁判放水/世界不动，还是纯对话的正常形态。

## 分类

人工逐条看 77 条，按主类计数（边界有重叠，数量是主类）：

| 类别 | 约数 | 例子 | 判断 |
| :--- | ---: | :--- | :--- |
| 纯说话 / 问答 / 复述 | 52 | 问酒、问死人、安报“两枚一杯”、医生答“十一个” | 正常；对话不改变持有/位置 |
| 姿态 / 观察 / 站位 / 擦拭 | 17 | 坐下、按住钥匙串、擦柜台、把灯芯捻低 | 正常；账本不建模姿势/表情/光线 |
| 同拍被抢先 / 最终状态没变 | 1 | 玩家拉门闩半寸，格蕾妮又推回；门最终仍关着 | 正常；不是“没发生”，是净变化为零 |
| 道具 / 位置细节未入账 | 7 | 湿外套挂钉子、抹布盖铁盒、瓶在柜台内挪半掌、杯在台面换位置 | 文本细节；外套/抹布不在 `items`，位置微调不换持有人 |
| 明确该落 `fact`/`phys` 却没落 | **0** | — | 没有发现系统性漏账 |

### 关键例子

- 第 1 拍格蕾妮把玩家的湿外套从椅背挂到墙角钉子：这是文本里的道具移动，但外套不在 `ContentPack.items`，也不在任何人 `holds` 里；账本没有可落的位置。**不是漏 op，是道具没建模。**
- 第 19 拍玩家把门闩拉开半寸，安/格蕾妮又推回：玩家 claim 被接受，但门的最终 `closed` 仍是 `true`，所以 deltas 为空；这是同拍净变化为零。
- 第 5 拍格蕾妮把瓶子从生客那侧挪回安手边：瓶子仍在 `counter`，只是台面位置变了；`holds` 只记持有人，不记台面坐标。
- 大量 NPC 的“清嗓子、捏帽子、抬下巴、看钥匙串”是对话姿态，落 op 反而会把账本灌满。

## 结论

- **77% 空结果不是缺陷**：绝大多数是正常对话/姿态；把 empty 当质量目标会逼裁判给每句话编 op。
- **唯一可选的改进是道具/位置**：外套、抹布、盒盖、台面坐标；这属于内容/表示层，不是裁判或调度。
- 不建议为降低 empty 去加“每拍至少一条可观测变化”的硬规则；那会把纯对话判成失败。
- 后续评估世界变化，应看 **净持有/位置/关系变化** 与**玩家可感知的后果**，不要只看 `empty_rate`。

## 风险

- 分类是人工主类计数，边界（说话 vs 姿态）有主观性。
- 单次 20 拍；第 17 拍的 `detectConflicts` 误报不在本分类内。
- 外套/抹布已在 C7 写进 `items` 并给初始 `holds`；门边钉子作为陈设承载点，铁盒盖有 `open`。台面内坐标仍不建模。见 [props-12.md](props-12.md)。
