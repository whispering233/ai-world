# T4/T5 合并后的 12 拍 smoke

> 目的：T4（claim 语义 + 现场优先）与 T5（旁白编排）合并后，确认 NPC 自相矛盾是否下降、旁白段落是否收敛、12 拍折场与 token 是否正常。**单次 12 拍仍不是回归证明**；没有同输入的前后对照。

## 1. 设置

| 项 | 值 |
| :--- | :--- |
| 命令 | `scripts/experiment-multi-round.ts --beats 12 --mode baseline --tag t4t5-baseline --force` |
| 模型 | `opencode-go/deepseek-v4.1-flash`（三个角色同档） |
| 内容 | `content/starter-town.json`（T3 的 opening/scene） |
| 玩家输入 | 脚本内置 `AUTO_LINES` 循环，12 条 |
| 产物 | `data/experiment/t4t5-baseline/baseline/`（不入库） |

## 2. 结果

| 指标 | 值 | T2/T3 smoke（10 拍） |
| :--- | ---: | ---: |
| 每拍均耗时 | 55.8s | 58.9s |
| 时钟推进 | 16 min / 12 拍 | 21 min / 10 拍 |
| 折场 | **1**（第 12 拍触发拍数阈值） | 0 |
| 裁决 / `no_rate` | 60 / 5.0% | 50 / 8.0% |
| 玩家侧 `no` | 3 / 12 | 1 / 10 |
| NPC 侧 `no` | **0 / 48** | 3 / 40 |
| `ok` + 空 `deltas` | 51 / 60（**85%**） | 37 / 50（74%） |
| 写操作 | `transfer` 1、`consume` 1、`phys` 3、`fact` 2 | `transfer` 5、`fact` 7、`phys` 2 |
| 输入 tokens / 拍 | 125,837 / 12 ≈ **10.5k** | ≈10.4k |
| 输出 tokens | 84,138 | 62,102 |
| 硬冲突 / op 失败 | 0 / 0 | 2（1 个脚本误报）/ 0 |
| 每拍段落数 | 3,2,3,4,3,2,4,2,5,3,3,4（8/12 ≤3） | 5–7 |

重复小动作（12 条 passage）：`清了清` 12 次（每拍一次）、`按了按` 6 次、`擦` 2 次、`刮了两下` 1 次。

## 3. 结论

1. **T4 的“现场优先 + 空 outward 不成 claim”有效**：这一轮 NPC 侧 0 条拒绝，上一轮的 3 条“拿已经不在原处的东西”没有复现。玩家侧 3 条拒绝仍是人自己按旧记忆输入（推门、推账本）；这要靠 UI 状态行，不是提示词。
2. **T5 把段落从 5–7 压到 2–5，但不是结构保证**：4/12 拍仍有 4–5 段。提示词能降低独白感，但不能保证“最多两段人物段落”。
3. **模板化小动作主要来自人物输出，不是旁白**：`清了清` 每拍一次，是科迪的 `outward` 自己带的；旁白只是照抄。下一步应给认知加一条“不要每拍重复同一个习惯动作/口头禅”，不要继续拧旁白。
4. **85% 的 claim 是 `ok` + 空 deltas**：世界变化只有 7 条写操作。T2–T5 改善的是“谁看见什么/怎么叙述”，没有改善“世界几乎不变”。这是 backlog 里“世界层三项缺陷”的问题。
5. **token 与折场正常**：10.5k/拍仍在 16k 内，12 拍按拍数折场一次；summary 进上下文没有把预算打爆。
6. **notes 频率不能归因**：脚本在 4 拍打印 `notes=1`，但没把 notes 写进 metrics；无法区分是 T2 的“无感知摘要”还是 T5 的“旁白漏写”。不要用这个数字下结论。

## 4. 对下一批的输入

| 方向 | 证据 | 代价 |
| :--- | :--- | :--- |
| UI 状态行 + “等一会儿” | 玩家 3/12 的拒绝来自旧记忆；世界只能靠玩家输入推进 | 低（纯前端） |
| `settled` 进度帧 | 55.8s/拍，裁判仍是最长段 | 低（一个可选字段 + 一次回调） |
| 硬聚焦“对谁说” | 四人每拍各产生 claim，群像与对话没有区别 | 中（API `to`、调度、UI chips） |
| `suggest` 3 条提示 | 玩家不知道该做什么；现有输入框只提示“说点什么” | 中（第 4 个模型角色 + 存储/UI） |
| 去模板化提示词 | `清了清` 12/12 拍 | 低（认知提示词 + 测试） |
| 世界层三项缺陷 | 85% 空结果 | 高（内容 + 裁判规则） |

**测法下限**：这是单次 12 拍，不能用来证明 `no_rate` 或质量的趋势；下一步若要 A/B，同条件至少跑 3 次并报分布。
