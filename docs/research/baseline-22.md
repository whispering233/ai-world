# 第三次 20 拍基线（baseline-22，2026-11-26）

- 模型：`opencode-go/deepseek-v4.1-flash`（cognition / referee / narration / suggest）
- 命令：`env -u PI_MODEL node --experimental-strip-types scripts/experiment-multi-round.ts --beats 20 --mode baseline --tag baseline-22 --force`
- 探针：默认短句；不加 `--long` / `--unlock` / focus。
- 检测器：C3 `scripts/conflicts.ts`（按 `commit` 的 `order` 结算）。
- 产物：`data/experiment/baseline-22/`（不入库）。
- 目的：baseline-20/21 的段落数分别是 17/20 与 12/20；按 backlog 的三次口径复测。

- ≤3 的拍：17 / 12 / 16；三分之二的样本在 3 段以内，中位数 16。
- `>3` 的拍：3 / 8 / 4；最多段落 4 / 7 / 7。
- 结论：baseline-21 的 12/20 是采样波动，不构成“段落稳定变长”。按 backlog 的口径，**不切结构化段落上限卡**；候选保留，等出现连续回退再看。

## 其他读数

- 三次 `hard/double`：baseline-20 的 1/1 是旧检测器误报；baseline-21/22 新检测器都是 0/0，`failedOps 0`。
- `no_rate` 5.0% / 7.1% / 8.0%，都低于 15% 下限；仍是“拒绝偏少”，不是稳定恶化。
- `facts/beat` 0.55 / 1.25 / 0.80；单次波动大，不能拿 baseline-21 的 1.25 当趋势。
- `empty` 77% / 60.6% / 71%；同样不能拿单次说世界变活。
- `know` 2 / 0 / 0；仍没有知识通胀。
- 三次都是 20/20 拍有提示、共 60 条。

## 风险

- 三次不是同一条轨迹，模型非确定；比较的是分布，不是逐拍对照。
- 默认短句 duration 全 0–3，不能读成“时间钉死”；长动作另见 [time-probe-smoke.md](time-probe-smoke.md)。
- 没有跑 focus/long/unlock；本轮结论只覆盖默认短句 baseline。
