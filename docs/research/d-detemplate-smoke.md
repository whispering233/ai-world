# D 去模板化后的 12 拍 smoke

> 目的：验证“不要每拍重复习惯动作”的认知提示是否降低模板化，以及新的“段落数 > 3”检查能不能作为测量。**单次 12 拍，不是 A/B**；没有同输入对照。

## 1. 设置

| 项 | 值 |
| :--- | :--- |
| 命令 | `scripts/experiment-multi-round.ts --beats 12 --mode baseline --tag d-detemplate --force` |
| 模型 | `opencode-go/deepseek-v4.1-flash`（三个角色同档） |
| 内容 | `content/starter-town.json`（T3 的 opening/scene） |
| 产物 | `data/experiment/d-detemplate/baseline/`（不入库） |

## 2. 结果

| 指标 | D 后（12 拍） | T4/T5 后（12 拍） |
| :--- | ---: | ---: |
| 每拍均耗时 | 80.3s | 55.8s |
| 时钟 / 折场 | 16 min / 1 | 16 min / 1 |
| `no_rate` | 6.7%（玩家 4/12，NPC 0/48） | 5.0%（玩家 3/12，NPC 0/48） |
| `ok` + 空 deltas | 47/60（78.3%） | 51/60（85%） |
| 写操作 | move 1、transfer 2、fact 8、phys 0 | transfer 1、consume 1、phys 3、fact 2 |
| 输入 tokens / 拍 | 135,633 / 12 ≈ 11.3k | 125,837 / 12 ≈ 10.5k |
| 输出 tokens | 103,451 | 84,138 |
| 每拍段落数 | 3,5,3,5,2,2,2,2,2,5,2,3（9/12 ≤3） | 3,2,3,4,3,2,4,2,5,3,3,4（8/12 ≤3） |

重复小动作（12 条 passage）：

| 词 | D 后 | T4/T5 后 |
| :--- | ---: | ---: |
| `清了清` | **5** | 12 |
| `按了按` | **1** | 6 |
| `刮了两下` | **0** | 1 |
| `擦` | 6 | 2 |

## 3. 结论

1. **去模板化提示有效，但只是方向性的**：`清了清` 12→5、`按了按` 6→1、`刮了两下` 1→0；`擦` 2→6（安的动作更多，属于内容，不是同一句模板）。单次 12 拍，不能排除采样波动；要证明得同条件跑 3 次。
2. **段落上限仍是软约束**：3/12 拍仍是 5 段，检查只记 notes，不改写。9/12 ≤3 比上一轮 8/12 好一格，但不能宣称“结构保证”。
3. **玩家侧 4/12 拒绝仍是旧记忆**：推门、推账本、从门口走到桌边；NPC 0 拒绝。状态行/此刻仍然是最直接的修复。
4. **78.3% 空结果**：世界变化只有 11 条写操作。D 不碰世界层，这个数字不该拿来做 D 的成败判据。
5. **耗时/token 上升不能归因**：80.3s vs 55.8s、11.3k vs 10.5k；单次运行方差很大（个别拍 115s），提示只多了一行。不要把这两项写成 D 的代价。

## 4. 局限

- 单次 12 拍；没有同输入的前后对照，也没有人工评分。
- 脚本不存 `notes` 内容；8 拍打印 `notes=1` 无法区分“无感知摘要”“旁白漏写”“段落数 > 3”，只能确定段落检查在 3 拍（5 段那三拍）会触发。
- 段落数按空行拆；一段里的多个人物不算多段，所以它是“排版密度”指标，不是“几个人开口”的指标。
