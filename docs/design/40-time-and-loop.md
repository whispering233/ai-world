# 40 时间、场景与主循环

## 1. 时间模型

| 概念 | 定义 |
| :--- | :--- |
| `clock` | 从创世起的**分钟数**，单调递增 |
| `busyUntil` | 每个实体"手上这件事完成"的时刻 |
| `beat` | **一拍**：一次结算 = 一条 `journal` = 一个回放单位 |
| `scene` | **一个场景**：一次装配 → 若干拍追加 → 一次折场（见 §2） |
| `fmt(clock)` | 唯一的时间展示出口，如 `第 3 天 · 傍晚` |

**没有等距 tick。** 世界按分钟变老，不按交互次数变老。
**一拍不是时间边界**，是事务边界；一拍的时长由 referee 给，可能 1 分钟，也可能 8 小时。

## 2. 场景（一等概念）

场景是**上下文的生命周期单位**，不只是"同一地点的连续时刻"。

| 时点 | 动作 |
| :--- | :--- |
| 进入 | **装配**：检索记忆（用满 25% 预算）、取 canon、算账本切片，拼出每个参与者自己的上下文 |
| 场景内 | **只追加**：每拍在尾部追加新文本，不改动前缀（缓存命中） |
| 退出 | **折场**：把该场景窗口压成 1–2 条 `experience`（可能是 `self` 条目），写一条 `journal.scene/fold` |

**强制折场条件**：12 拍 或 16k tokens，先到即折。折场是唯一的压缩入口，同时是成长入口。

场景不单独落盘：场景边界由 `journal.scene` 与 `scene/fold` 记录推出。

## 3. 主循环

```text
loop:
  if 无当前场景: 装配场景（检索 + canon + 账本切片）
  actors  = 被叫到的人(场景)
  claims  = 收集(actors + 玩家)
  if claims 为空: clock = min(busyUntil); continue
  r       = referee(claims, 场景切片, 账本, canon)   // 一拍一次
  账本原子提交(r); 追加渲染(r); 写日志(clock, scene, claims, r)
  clock   = min(busyUntil)
  if 拍数 ≥ 12 或 tokens ≥ 16k 或 场景为空: 折场()
```

## 4. 被叫到的人

一拍参与者 = 玩家（总是） ∪ { 有张力者（`max(heat) ≥ 0.5`） ∪ 本拍被直接作用者（被点名、被告知、被攻击） }

**在场 ≠ 醒着。** 同 `placeId` 只是位置属性，不作为唤醒条件。
沉默者的自救机制：`drive` 受阻会 `heat +0.2`，越沉默越烫，迟早被叫到。

## 5. 时长归属

`duration` 属于**世界事实**，不属于角色意图，因此由 referee 给出。

| 规则 | 值 |
| :--- | :--- |
| 缺省 | 1 分钟 |
| 上下限 | `[0, 1440]` |
| 超过一天 | 必须显式是长动作（睡、远行、养伤） |
| 空间类动作 | 可由距离/速度算术推导，不查动作时长表 |

角色与玩家可以在文本里表达时长（"我等到傍晚"），referee 采纳或修正；最终值以 referee 为准。

**不做动作时长表**：那是能力清单的第三种形态，会长不完。

## 6. 时间只有一个出口

叙事文本**禁止写绝对时间**，只能用 `fmt(clock_before)` 与 `fmt(clock_now)` 推出的相对说法（"天已经黑了"）。

于是"文本说傍晚、clock 说上午"这类矛盾在结构上不可能发生。这比任何校验都值钱。

## 7. 世界签名（成长许可）

| 条件 | 是否算签名 |
| :--- | :--- |
| `verdict: ok` 且账本有变化 | 是 |
| `verdict: no` | 是（挫败也是经历） |
| `verdict: ok` + `deltas: []` + `duration ≥ 240` | 是（时间流逝本身有分量） |
| 其余 | 否 |

折场时若本场满足上述任一条件，则允许写 `self` 条目（仍受"稀缺"与"具体"约束，见 30 §4）。

## 8. 推进与暂停

- v1：**玩家在场时，时间只由主张推进**；不按真实墙钟流逝，慢读者不被惩罚。
- 玩家离线：世界不推进（v1）。
- `advanceTo(t)` 已存在于主循环形态中，离线粗粒度推进是**纯增量**，不改变架构（见 backlog）。

## 9. 明确不做

- 等距 tick / 回合计数
- 真实墙钟推进
- 多时间尺度嵌套
- 预排的导演事件队列
- 后台心智活动
- 场景表落盘（场景是派生概念）
