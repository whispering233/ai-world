## 4. 执行与验证约定

**已固化的小约定**：一人一拍一条 claim（"边说边拔枪"是一条，多条 `deltas`）；`rel` 单向；`observations` 是结构化的 `claimId` 列表 + 一句结果摘要；玩家无 `core`/`drives`/`inner`。

- 每张卡独立 commit；失败可单独回滚。
- 每张卡验收 **≤3 条**，subagent 不得扩展验证范围。
- UI 卡（W12）验证截图 **≤8 张**。
- fixture/faux 优先：凡能确定性验证的，不调真实模型。
