# 20 裁判（referee）

## 1. 定义

referee 不是角色、不是模块、不是 agent，而是一个**函数**：

```text
referee(本拍 claim[], 场景切片, 账本, 相关 canon) →
  { order, verdicts[], observations[], driveHits[] }
```

它对应四个职责：判定主张是否成立、决定账本写入、推进时间、决定谁能看见什么。

**它不是导演。** 导演回答"接下来往他们身上扔什么"（storylet 层，v1 不实现）；裁判只回答"这个主张成立吗"。裁判不能编，只能判。

## 2. 契约

| 字段 | 含义 |
| :--- | :--- |
| `order` | 本拍 claim 的结算顺序，表达"谁的手快"。**只在拍内有效** |
| `verdicts[]` | 每条 claim 的结果：`{ claimId, ok, reason?, deltas[], duration }` |
| `observations` | 每个在场实体实际可感知的内容：被其感知的 `claimId` 列表 + 一句结果摘要（**结构化**，非自由文本） |
| `driveHits[]` | `{ entId, driveId, delta }`，驱动热度增减 |

`verdict` 只有三种形态，全部合法：

| 形态 | 语义 |
| :--- | :--- |
| `ok` + `deltas` 非空 | 发生，且改变了世界 |
| `ok` + `deltas` 为空 | 发生，但未改变账本（话说了，事没成） |
| `no` + `reason` | **不成立**：话照说，账不动 |

`reason` 会写回该角色的 `experience`，成为下一轮的后果反馈。这是"约束由后果施加"的落点。

**冲突裁决**：同一拍内的互斥主张（两人同抢一物、两人同时开枪）必须由 referee 自己解决，`deltas` 中**只出现成立的那一方**。`order` 仅用于叙述顺序，不参与状态写入。否则 `apply` 会双重写入。

## 3. 驱动方式

- 由**调度器**驱动，不是 LLM 自己触发。
- **一拍一次批量结算**，不是每条 claim 一次调用。
- 没有 claim 的拍不发生（事件队列保证）。

批量结算的三个理由：并发冲突只有批量可见（两人同抢一物）；成本为 O(拍) 而非 O(claim)；账本原子性。

## 4. 输入切片（硬上限，不靠"按需"）

| 段 | 内容 | 上限 |
| :--- | :--- | :--- |
| claims | 本拍全部对外主张 | 4 条，超出顺延至下一拍 |
| 场景切片 | 同一 `placeId` 的实体 + 相关账本字段 | 只给相关实体，不给全账本 |
| canon | 与本拍主张相关的 fact | 8 条 |

## 5. 校验位置

**没有审核阶段。** 校验 = 每个 op 的前置条件。不合法 → 该 op 失败、记录原因、其余 op 正常提交。

不做的事：动作词表、物理推算、常识规则库、"踹/踢/推"映射。这些不是校验，是第二份世界模型。

## 6. 渲染器边界

渲染器可以把结果写得漂亮，也可以补细节（光照、动作、语气）。
**但它产出的文本永不写回 `experience` / `self` / `facts`。** 玩家读到的细节是"传闻"，不是"事实"。

### 6.1 旁白失败降级

裁判已经 commit 之后，渲染调用仍可能抛错或返回空文本。这时**不能丢拍**：

- 先写 `journal`（账本凭据），再写 `passage`；passage 写失败不影响已结算的拍。
- 旁白失败 → 用确定性格式把 `NarrationEvent` 的事实列成摘要（`source: 'fallback'`），并在 `notes` 记录原因。
- 不重跑裁判，不改写已发出的文本，不编造新事实。
- 空文本也算失败；`findAbsoluteTime` 只报告，不触发降级（不改写是硬规则）。

## 7. 体检指标

```text
no_rate = verdict:'no' 的次数 / claim 总数
```

| 区间 | 判断 |
| :--- | :--- |
| 15%–40% | 正常 |
| 长期 ≈ 0 | 裁判在放水，世界失去代价 |
| 长期 > 60% | 裁判在刁难，玩家会觉得世界不讲理 |

必须按"应当有风险的 claim"分桶统计，否则低风险玩法会污染指标。

## 8. 已知失败模式

| 失败 | 表现 | 处置方向 |
| :--- | :--- | :--- |
| 顺从性 | 什么都被允许 | 调整提示与分桶 `no_rate` |
| 自相矛盾 | 同一事实两拍给出不同判定 | 喂 canon 切片；记录判定历史 |
| 过度裁决 | 连买一杯酒也要裁决 | 允许无歧义 op 走直写窄通道（P2） |
