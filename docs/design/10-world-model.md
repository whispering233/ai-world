# 10 世界模型

## 1. 三份数据

| | 内容 | 写者 | 可变性 |
| :--- | :--- | :--- | :--- |
| `passage` | 叙事、对话、内心独白的**呈现文本** | 渲染器 | 只增，永不修改 |
| `facts` | 从此不可否认的公共事实 | referee | 只增；推翻旧条目 = 新增 + `supersededBy` |
| `ledger` | 可被外界观测/验证的状态 | referee | 每拍可变 |

**文本不是证据。** 账本与文本冲突时以账本为准，且**不 retcon**：已经发出的文本永不改写，只让后续生成向账本收敛。

## 2. 账本字段（5 类）

| 字段 | 含义 | 形态 |
| :--- | :--- | :--- |
| `at` | 位置 | `EntId → PlaceId` |
| `holds` | 持有物 | `EntId → {ItemId: count}` |
| `phys` | 物理属性（门锁、伤势、灯火、火势…） | `EntId → {string: number\|boolean}`，**键开放** |
| `rel` | 关系强度 | `EntId → {EntId: -3..3}` |
| `knows` | 是否知情 | `EntId → FactId[]` |

`phys` 是开放口袋，唯一约束：**键必须能被一句物理描述解释**，且 v1 手工维护键表。

**`knows` 的差集就是全部悬疑与秘密**，因此不另建秘密系统。

## 3. 写操作（6 个）

| op | 作用 | 前置条件（在 op 内部检查） |
| :--- | :--- | :--- |
| `move` | 改 `at` | 来源地存在；目标地可达 |
| `give` / `take` | 改 `holds` | 给出方确实持有足够数量 |
| `phys` | 改 `phys[key]` | 目标实体存在 |
| `rel` | 改 `rel` | 双方存在；结果**饱和**到 `-3..3`（不拒绝） |
| `learn` | 新增 fact + 授予 `knows` | 授予对象存在；fact 未被 superseded |

**没有独立的审核阶段。** 校验就是每个 op 自己的前置条件；不合法时该 op 返回失败并记入日志。

## 4. 五条不变式

1. 文本不是证据。
2. 不 retcon。
3. 只有 referee 能写 `ledger` 与 `facts`。
4. `fact` 只增不改。
5. 每拍至少一条可观测变化（账本 delta / 对外文本），否则判为空转并压低其优先级。

## 5. `knows` 与 `belief` 的分工

| | 含义 | 存放 | 可错性 |
| :--- | :--- | :--- | :--- |
| `knows` | 此人**是否**知道某条公共事实 | 账本 | 不可错（由 referee 授予） |
| `belief` | 此人**以为**什么 | 角色私有 | 可错，可被谎言改写 |

人物说错话是合法的：谎言进入世界的方式是"新增一条 fact（他说过这话）+ 授予听众 knows"，原事实不受影响。

## 6. 记忆的不对称（设计原则，不是妥协）

> **世界记得少而硬，人记得多而软。**

- 账本：6 个 op，只记别人能验证的。
- 角色 `experience`：不受 op 限制，记一切它经历与在意的事，只受上下文预算约束。

因此：一次深夜长谈不会改变任何账本，但当事人记得，并会在下一轮改变它说话的方式。这是"细腻的行为也能留下后果"的唯一通道。

代价（明确接受）：粗暴的、可见的、有物的行为，比细腻的内在行为更容易被世界记住。
