# 30 人物与认知

## 1. 四层状态，三种可变性

| 层 | 内容 | 写者 | 可变性 |
| :--- | :--- | :--- | :--- |
| `core` | 散文 200–400 字：出身、创伤、身体、口头禅、不能碰的东西、说话节奏 | 作者（编辑期） | **运行时只读** |
| `drives` | `{ text, heat }` 列表 | 角色（仅增删）+ referee（仅 heat） | 半可变 |
| `beliefs` | `{ 对象: 说法 }` | 角色 + referee 的 fact/knows | 自由可变 |
| `experience` | append-only；`kind: seen\|self` | 角色 | **只追加** |

**没有单独的"人物定义文件"，也没有"人物快照文件"。** 某一刻的人物 = `core + drives + beliefs + 检索(experience)` 拼出来的。

`core` 的写法约束：**写"是什么"，不写"会什么"。** 前者产生性格，后者产生技能表。

## 2. 单次调用

每个"被叫到"的人物，每拍一次调用（聚焦模式下只有目标被叫到，见 40 §4）：

```text
输入 = core + drives + 相关 beliefs + 检索到的 experience + 场景 + 上拍后果
输出 = 一段自由文本（不要求结构化）
```

**没有阶段、没有工作记忆对象、没有中间产物。** 人物是一个 actor：收消息、回消息、休眠。循环在世界层（见 40）。

**现场优先**：行动前先看现场（账本现状、持有物、`phys`、裁判给本人的感知摘要）；现场与记忆冲突时以现场为准，不要碰已经不在原处的东西。这是一条判断规则，不是动作白名单。

system 顺序固定：`core/voice → 输出指令 → canon → drives/beliefs/记忆`。缓存按前缀匹配，所以易变段必须排在后面。

## 3. 输出切分（已定）

| 字段 | 内容 | 去向 |
| :--- | :--- | :--- |
| `inner` | 没说出口的话、忍住的反应、自我判断 | 只写 `experience`，`kind:'thought'`，`w=1`；**不进裁判、不进旁白** |
| `outward` | 说出口的话、做出的动作 | 作为 claim 交给 referee；**为空表示这一拍没开口**，不生成 claim |

一次切分，不是 schema。它的价值是让**"忍住没说"**成为合法且可记录的行为。

## 4. 成长

成长的载体是 `experience` 里 `kind:'self'` 的条目。**没有独立的修订机制**——自我修订只是权重更高的经验。

三道闸：

| 闸 | 规则 |
| :--- | :--- |
| 只追加 | 旧 `self` 条目永不改写；要推翻就再写一条 |
| 要签名 | 本拍 referee 判了 `ok`（改了账本）或判了 `no`，或 `ok + deltas:[] + duration ≥ 240`（时间流逝） |
| 稀缺 | 触发需 `max(heat) ≥ 0.8` 或 `≤ 0.1`；每 10 拍最多 1 条 |

`self` 条目的写法约束：**必须是具体的人、事或决定，不许是感悟。** 反例（禁止）："我明白了信任的珍贵"。正例："我不再指望他替我说话"。

**当前口径**：

- 签名取**本拍**（裁判返回后才判），且以**落账**为准：`ok` 但整条回滚的 claim 不算签名。因此自我修订在结算末尾才落：认知阶段只暂存，不写入。
- 稀缺以**拍号窗口**实现：最近 10 拍内至多 1 条（`self` 条目的 `ref` 存拍号，旧 journal 没有 `ref` 的视为很久以前）。不按场景算：场景长度不受控，一次长睡折场只剩 1 拍，按场景算会让闸放松一个数量级（实测：20 拍长出 12 条）。
- `self` 条目的检索权重取 `w = 3`（`seen` 为 2），与 §5 的 `+0.3` 加成叠加。
- 未开闸的自我修订 **直接丢弃**，不降级成普通记忆；一次从未发生的自我修订不该在检索里占位。
- `heat` 极值触发（`max(heat) ≥ 0.8` 或 `≤ 0.1`）**尚未实现**。

`drives.heat` 的调整：被满足 −0.2，被阻碍 +0.2，由 referee 的 `driveHits` 给出，角色不能自己加温。

本拍新增的记忆与 `driveHits` 必须进 journal（`experience` / `driveHits` 字段）；未落 journal 的拍不推进记忆，`replayCharacters` 只读 journal。

## 5. 检索

```text
score = w × 0.5^((now − t) / 48) + (kind == 'self' ? 0.3 : 0)
```

取前 12 条。无向量、无重要性二次打分、无反思生成。

## 6. 上下文预算（五段）

单拍上限 **16k tokens**（已定）。下表是上限内的**分配比例**，不是绝对值。

| 段 | 占比 | 16k 下的近似落点 |
| :--- | :--- | :--- |
| 指令与叙述者声音 | 5% | ~800 |
| lorebook / canon 命中 | 20% | ~3.2k |
| 账本切片（仅相关实体） | 15% | ~2.4k |
| 私有记忆（检索结果） | 25% | ~4k |
| 最近文本 | 35% | ~5.6k |

每拍实测的 token 数必须写进 `journal`（降本与降级判断的唯一依据）。“最近文本”段现在同时包含自己那句与裁判给本人的感知摘要（决策 #42），拍内增量比旧口径大约翻倍，比例需重新校准。
比例需用真实回合校准，首周必调。

## 7. 玩家（半 actor）

玩家与世界里其他实体**不同构**：

| 层 | 玩家 | 理由 |
| :--- | :--- | :--- |
| `core` | **无** | core 是别人对你的设定；玩家自己就是自己，给 core 只会退化成角色卡式自我暗示 |
| `drives` | 无 | 玩家的意图由输入直接表达 |
| `beliefs` | **有** | 否则玩家无法“记得”自己被骗过 |
| `experience` | **有** | 否则读到的历史只存在于 `passage` 里，几十拍后会只剩屏幕、没有记忆 |
| `inner` | **不生成** | 玩家自己在脑子里想，不为它花 token |
| claim | **输入原文即 claim，且是未裁决主张** | 不解析、不改写；人物看到的是“玩家提出”，不是“已发生” |
| 被 `no` 驳回 | `reason` 写回该角色的 `experience` | 与 NPC 同样走后果反馈；玩家侧是否显示理由仍是 backlog，当前只能从正文推断 |

结果：一拍里玩家不产生认知调用，只付裁判与渲染的钱。

## 8. 明确不做

- 感知/评价/目标/选择的阶段拆分
- 工作记忆作为独立持久化对象
- 一次调用排出一串计划再逐条执行（会退化成剧本）
- 背景心智活动（没人看的时候继续"思考"）
- 把 `inner` 交给旁白或裁判（它会变成玩家能读到的“读心术”）
- 把 `inner` 当成 claim（没出口的话不改变世界）
- 每回合都能改变自我（会变成人格湍流）
